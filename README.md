# Probability_passing_exam

Today, while studying for my january exams i asked myself the following question : 
What is the probability to pass an exam of 40 True or False questions if I answer randomly (without studying) ?

Instead of simply guessing I coded it in python and estimate the probability empirically using Monte Carlo simulations.

This project models an exam where :
  Each question has two possible answers (True / False)
  Each answer has a 50% chance of being correct
  The final grade is the number of correct answers
  To pass the exam the grade should be greather than 10 .

My probability of passing the exam anwering randomly is 0.9996.
